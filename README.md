# FBD

Este repositório contém o projeto **FinanCerto**, desenvolvido para a disciplina de Fundamentos de Banco de Dados (FBD).

O **FinanCerto** é uma solução pensada para **MEIs e microempreendedores**, que busca oferecer uma visualização clara e acessível de seus **lucros e vendas brutas**.

---

### Conteúdo do Repositório

* **Scripts SQL:** Inclui todos os scripts SQL utilizados na disciplina para a criação e manipulação da base de dados do projeto.
* **Aplicação em Python (API):** Contém a implementação da API em Python que interage diretamente com a base de dados, demonstrando a aplicação prática dos conceitos de banco de dados.
